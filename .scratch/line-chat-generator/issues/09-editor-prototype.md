# 編輯介面：做一個粗略版讓你實際點點看

Type: prototype (HITL)
Status: resolved
Blocked by: —

## Question

編輯對話的介面要怎麼操作？目前的方向是「像聊天一樣輸入」：底下選這則是誰說的，打字按 Enter 加進去；點預覽裡的訊息可以修改或刪除；可以拖拉排序。

做一個粗略版本實際操作，決定：

- 切換發話者的方式（下拉選單、頭像按鈕列、快捷鍵）
- 修改既有訊息的方式（直接在預覽上改，或跳出編輯框）
- 每則訊息的日期、時間、已讀在哪裡設定（日期分隔線是自動產生的，見「時間和已讀的規則」）
- 整段對話設定、參與者管理、對話清單（新增、複製、刪除、匯出、匯入）放在畫面的哪裡
- 在手機瀏覽器上能不能用

## Answer

用試做版比較了四種做法，選定 **D：照 A 的操作方式，把輸入訊息區移到左欄、跟對話清單放在一起**。試做檔是 [prototype/editor-prototype.html](../prototype/editor-prototype.html)，用 `?variant=A`、`B`、`C`、`D` 切換。

**畫面分成三欄**

| 位置 | 放什麼 |
|---|---|
| 左欄上半 | 對話清單：新增個人對話、新增群組、複製、刪除、匯出這段、匯出全部、匯入 |
| 左欄下半 | 輸入訊息區 |
| 中間 | 手機預覽。上方有「單頁截圖」「長截圖」「下載 PNG」三個按鈕。預覽會依視窗高度縮放，整支手機一次看得完，不用捲動 |
| 右欄 | 參與者（名字、頭像、誰是我方、新增和移除）、對話設定 |

**新增訊息**
- 點參與者的頭像標籤，選這則是誰說的。
- 打字後按 Enter 送出；Shift+Enter 換行；Tab 換下一位發話者。

**修改訊息**
- 點預覽裡的訊息，旁邊會跳出小視窗。
- 小視窗裡可以改：
  - 發話者
  - 內容
  - 日期、時間
  - 已讀：只有我方的訊息有；群組可以改已讀人數
- 小視窗裡也可以上移、下移、刪除。

**排序**
- 在預覽裡直接拖拉訊息。

**只做電腦版**
- 網站只考慮在電腦的瀏覽器上使用。
- 手機版的介面不做。

**沒有選的做法**
- B：用表單編輯，一則訊息一列。
- C：直接在 LINE 畫面上改文字，用小工具列改時間和已讀。
- A：原本的版本，輸入區放在預覽下方。

這些都還留在試做檔裡，可以切換回去看。試做檔還沒有 commit，留在 `.scratch/` 裡。
