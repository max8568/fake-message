# 選定轉 PNG 的套件，以及長截圖最多幾則訊息

Map: [LINE 對話產生器](../map.md)
Type: grilling (HITL)
Status: resolved
Blocked by: 02

## Question

根據「比較把網頁畫面轉成 PNG 的套件」的調查（[research/02-html-to-png-libraries.md](../research/02-html-to-png-libraries.md)），決定：

- 用 snapdom，還是比較穩定、但不能處理太高圖片的 modern-screenshot
- 長截圖要不要限制訊息數量：
  - 限制在約 100 則左右：每個瀏覽器都能輸出，也不靠 snapdom 剛加上一週的分段接圖功能
  - 不限制：要靠 snapdom 分段接圖，實作時要在 iPhone 實機上測過
- 超過上限時網站要怎麼做：擋住不讓輸出、提示改用單頁截圖，或是自動拆成好幾張
- 實作前要不要先在 iPhone 實機上照調查第 4 節的方式試一次

注意：調查是以 1170px 寬計算的，後來的決定改了兩種輸出的尺寸。

- 單頁截圖是 1320×2868px，每個瀏覽器都能輸出。
- 長截圖是 880px 寬（2 倍）。iPhone 上最高 16,384px，等於 8,192pt。實機截圖量到一則單行訊息約 34pt 高、訊息間隔約 10pt，所以單行訊息大約可以放 186 則。訊息有好幾行時，可以放的則數會比較少。

## Answer

**套件**
- 用 snapdom（`@zumer/snapdom`），版本要鎖定，不自動升級。
- 要升級時，先在 Chrome 上重新測過單頁截圖和長截圖。

**長截圖的高度上限**
- 輸出的 PNG 最高 16,384px。長截圖是 2 倍解析度，這個高度等於畫面上的 8,192pt。以單行訊息估算，大約可以放 186 則。
- 超過上限時：
  - 下載按鈕不能按
  - 畫面上提示「對話太長，請複製成兩段」
- 每段對話實際能放幾則，要看訊息有多長，所以是用輸出的高度來判斷，不是用訊息則數。
- 不靠 snapdom 剛加上的分段接圖功能。這個高度在每個電腦瀏覽器上都能直接輸出。
- 單頁截圖是 1320×2868px，不受這個上限影響。

**要測的瀏覽器**
- 只測 Chrome。
- 網站只在電腦上用（見「編輯介面：做一個粗略版讓你實際點點看」），所以 iPhone 的限制不用管。
