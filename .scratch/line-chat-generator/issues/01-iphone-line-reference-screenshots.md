# 收集 iPhone LINE 實機截圖當比對標準

## Question

用 iPhone 上的 LINE 截一組參考畫面，之後畫面數值、時間格式、已讀樣式都以這組截圖為準。用測試對話就好，不要有真實內容。

需要的截圖（每張都是原始 PNG，不要裁切、不要壓縮）：

1. 個人對話，淺色模式：雙方各有幾則訊息、我方訊息有已讀、畫面裡有一條日期分隔線
2. 個人對話，深色模式：同上
3. 群組對話，淺色模式：至少三位對方，有人連續發兩則以上、我方訊息有「已讀 N」
4. 群組對話，深色模式：同上
5. 有一則很長、會換行的訊息
6. 標題列左上角有未讀數字的畫面

同時記下：iPhone 機型、iOS 版本、LINE 版本、LINE 的字體大小設定。

截圖放到 `.scratch/line-chat-generator/reference/`。

## Answer

收到 7 張截圖，都放在 [reference/](../reference/)。量到的顏色和尺寸、觀察到的規則，完整寫在 [research/01-reference-observations.md](../research/01-reference-observations.md)。

- **裝置**：iPhone 17 Pro Max、iOS 27、LINE 26.3.0，LINE 的字體大小跟隨 iPhone 設定。
- **截圖格式**：
  - 1.jpg–5.jpg 是用 LINE 內建「截圖」功能截的，880px 寬（2 倍），沒有狀態列、標題列和輸入框。
  - 1-a.png 和 6.png 是 iPhone 原始截圖，1320×2868（3 倍）。原始檔是 Display P3 色彩，已經另外轉成 sRGB 版本。

跟規劃不一樣、會影響其他單子的發現：

- **螢幕寬度不同**：這支 iPhone 的畫面寬度是 440pt（1320px），不是規劃時假設的 390pt（1170px）。輸出要用哪一個寬度，改到「整段對話設定的選項」決定。
- **連續訊息的合併規則**：要同一個人、同一分鐘內發的訊息才會合併。合併後只有第一則顯示頭像、名字和尾巴，只有最後一則顯示時間。超過一分鐘的訊息就各自顯示。這條規則改到「時間和已讀的規則」決定。
- **深色模式的我方氣泡是灰色**：顏色是 #595959，不是綠色。

沒有截到的畫面：

- 12 小時制的時間
- 「昨天」的日期分隔線
- 跨年時的日期分隔線

這三項會在「時間和已讀的規則」裡用推測的方式決定。
