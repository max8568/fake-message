# 整段對話設定的選項

Map: [LINE 對話產生器](../map.md)
Type: grilling (HITL)
Status: resolved
Blocked by: 01

## Question

依照參考截圖，決定整段對話設定要給哪些選項、每個選項的範圍和預設值：

- 手機尺寸：規劃時假設 iPhone 390pt 寬（輸出 1170px）。實機是 iPhone 17 Pro Max，440pt 寬（輸出 1320px）。要用哪一種，要不要能切換
- 手機狀態列：時間（要不要預設跟截圖日期、最後一則訊息的時間連動；12／24 小時制跟著對話的設定）、靜音圖示、電量數字、訊號格數、Wi-Fi 或行動網路（iPhone 截圖本來就不會拍到動態島，所以不用畫）
- 標題列：對方名字或群組名稱、群組人數、左上角未讀數（上限多少、超過時怎麼顯示）
- 聊天背景：純色要給哪幾種、要不要內建背景圖，淺色和深色模式各自的預設
- 下方輸入框：顯示或隱藏

參考：[research/01-reference-observations.md](../research/01-reference-observations.md)

## Answer

**手機尺寸**：只做 440pt 寬，也就是 iPhone 17 Pro Max 的寬度。這是實機截圖的尺寸，不能切換。

**兩種輸出**（取代原本的單頁截圖、長截圖定義）

| | 單頁截圖 | 長截圖 |
|---|---|---|
| 樣子 | iPhone 整個螢幕的原始截圖 | LINE 內建「截圖」功能的輸出 |
| 狀態列、標題列、輸入框 | 有（輸入框可以關） | 都沒有，只有對話區 |
| 尺寸 | 1320×2868px（3 倍），固定一個螢幕高 | 880px 寬（2 倍），長度不限 |
| 訊息太多時 | 只顯示最後一個螢幕的內容 | 整段對話都放進去 |

- 不提供其他組合，例如有狀態列但長度不限的截圖。真的 iPhone 和 LINE 都做不出這種圖。

**淺色和深色模式**
- 每段對話自己設定，預設是淺色。

**手機狀態列**（只有單頁截圖有）
- **時間**：預設是最後一則訊息的時間，可以自己改。12／24 小時制跟著這段對話的設定。
- **靜音圖示**：可以開或關，預設關。
- **電量**：0 到 100，預設 100。低於 20 時電池變成紅色。
- **訊號**：0 到 4 格，預設 4 格。
- **網路**：Wi-Fi、5G、4G、不顯示，四個選一個，預設 Wi-Fi。

**標題列**（只有單頁截圖有）
- **個人對話**：標題自動顯示對方的名字，不能另外改。
- **群組對話**：
  - 群組名稱自己填。
  - 名稱後面括號裡的人數，預設等於參與者人數。可以改大，不能比參與者人數少。
- **未讀數**：顯示在返回鍵旁邊。填 0 就不顯示，可以填 1 到 999。超過 999 時 LINE 怎麼寫，截圖裡沒看到，所以上限是 999。
- **右邊的圖示**：個人對話和群組都是同樣四個，搜尋、通話、記事本、選單，不能改。

**聊天背景**
- 只用 LINE 預設的顏色：淺色模式 #D0D8E4，深色模式 #121212。
- 不能自己選顏色，也沒有背景圖。

**輸入框**（只有單頁截圖有）
- 預設顯示，可以關掉。
