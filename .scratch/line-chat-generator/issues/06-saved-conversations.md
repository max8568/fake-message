# 瀏覽器裡要能存好幾段對話，還是一次只有一段

Map: [LINE 對話產生器](../map.md)
Type: grilling (HITL)
Status: resolved
Blocked by: —

## Question

瀏覽器裡要能存好幾段對話、從清單切換，還是一次只編輯一段（另一段要靠匯出、匯入 JSON 切換）？要不要內建幾段範例對話讓人一打開就有東西可以看？匯出的 JSON 要不要包含格式版本號，讓之後改版時舊檔案還能讀？

## Answer

- **存好幾段，在對話清單裡切換**：可以新增、複製、刪除。要從另一位參與者的角度看同一段對話，就複製一份再換我方。
- **自動存**：每次修改都會自動存進瀏覽器，沒有「儲存」按鈕。
- **對話清單上不另外取名字**：每段顯示三樣資訊：
  - 標題列上的名字（對方名字或群組名稱）
  - 我方是誰
  - 最後修改時間
- **刪除前跳一次確認**：刪了就不能復原。
- **匯出和匯入**：
  - 匯出有兩個按鈕：「匯出這段」和「匯出全部」。「匯出全部」是給使用者備份用的，瀏覽器清掉網站資料時，對話會全部不見。
  - 匯入一律新增成新的對話，不覆蓋任何現有的對話。
- **匯出的 JSON 會記檔案格式的版本號**：網站改版後讀到舊檔案時，會自動轉成新格式。
- **範例對話**：
  - 第一次打開網站時，會先放兩段範例，一段個人對話、一段群組對話。
  - 範例跟一般對話一樣，可以改，也可以刪。刪掉後不會再出現。
- **打開網站時顯示哪一段**：顯示最後修改的那一段。第一次打開時，顯示範例裡的個人對話。
- **換我方時已讀不會跟著改**：
  - 已讀是每則訊息自己的設定，換我方時不會被改掉。
  - 只有我方的訊息會顯示已讀。原本我方的已讀會被藏起來，換回來時又會出現。
  - 新增訊息時，我方的訊息預設是已讀。
